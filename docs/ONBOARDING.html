Docker Composev2 (docker compose)

2. Setup

git clone https://github.com/alphatrann/outline.git
cd outline
git checkout 05ef55e

nvm install 22.23.0 && nvm use 22.23.0
corepack enable --install-directory ~/.local/bin   # ~/.local/bin must be on PATH before the old yarn

docker compose up -d redis postgres
yarn install --immutable
# create .env as described in section 3
yarn build:server                         # required before the first migration
NODE_ENV=development yarn db:migrate
yarn dev:watch

Open http://localhost:3000 (plain HTTP, no certificate needed).

3. Environment variables

Create .env in the repo root. The Sequelize CLI reads only this file, so all values below must be here.

SECRET_KEY=<openssl rand -hex 32>
UTILS_SECRET=<openssl rand -hex 32>
URL=http://localhost:3000
FORCE_HTTPS=false
DATABASE_URL=postgres://user:pass@127.0.0.1:5432/outline
REDIS_URL=redis://127.0.0.1:6379
FILE_STORAGE=local
FILE_STORAGE_LOCAL_ROOT_DIR=/absolute/path/to/outline/data

Also edit .env.development: it overrides .env when running the app. Set URL=http://localhost:3000 and add FORCE_HTTPS=false. Otherwise the page loads assets from https://local.outline.dev:3001, which fails with a TLS error unless mkcert certificates exist.

6. Known issues

  • yarn db:migrate fails with getaddrinfo ENOTFOUND postgres or client password must be a string: run it with NODE_ENV=development and set DATABASE_URL in .env.
  • Migration fails with Cannot find module build/server/scripts/...: run yarn build:server first.
  • Browser shows a TLS error: browser cached HSTS for localhost. Use incognito, or clear it at chrome://net-internals/#hsts, and open the http:// URL.
  • corepack enable fails with EACCES on /usr/local/bin: use --install-directory ~/.local/bin.
  • make build fails: docker-compose.yml has no outline service.
  • Ports 5432 / 6379 busy: stop the local service or change the ports in docker-compose.yml.
  • Certificate warning: re-run yarn install-local-ssl.
